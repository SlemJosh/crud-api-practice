# CRUD API Practice (Refresher Session 2)

This project is part of my full-stack refresher series with Marty the AI (aka ChatGPT).  
It covers the basics of a CRUD API built with Express.js and Node.js.

## 🔧 Features
- In-memory user data
- Full CRUD routes:
  - `GET /api/users`
  - `GET /api/users/:id`
  - `POST /api/users`
  - `PUT /api/users/:id`
  - `DELETE /api/users/:id`
- Tested using Thunder Client

## 📦 Technologies Used
- Node.js
- Express
- Thunder Client (VS Code Extension)

## 💡 Purpose
To reinforce core backend concepts like routing, JSON handling, and CRUD logic.
